# Helder Mendes Portfolio

Portfolio built with **Next.js 15, TypeScript, and Tailwind CSS v4**.

Showcasing a 15+ year career transition from **Art Director (Philips, DaimlerChrysler)** to **Full Stack Developer**. Blends high-end editorial aesthetics with modern engineering. 

**Features**: 
- 🎨 Bento-box layout
- ✨ Framer Motion animations
- 🛠️ TypeScript & Tailwind v4
- 🌍 Full EN/NL localization
- ⚡ Design-first & high performance

---

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
